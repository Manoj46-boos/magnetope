# The feel bible

Generated by `npm run docs` from the feel table in `src/game/feel-table.ts` and the tuning, hit-stop and spacing constants it quotes. The suite re-renders this file and compares it byte for byte, so a hand edit or a code change without a re-render fails the build (R-GF-14).

Every state transition that carries feel is named with its juice stack, its audio map and what the stack costs. The event names come from the simulation's own vocabulary, so a row for an event the sim never emits fails the compile, and the suite fails the build if the render, game or audio layers listen to an event this table does not carry. Rows that stage nothing say so — silence is a choice the bible keeps visible.

## The state machine

MAGNO lives in five states — airborne, attached, charging, repelled, recovering — and the game in five phases — play, paused, cleared, ending, busy. The transitions below are the ones the player can feel; the rest (bookkeeping, hazard clock, ghost recording) stage nothing by design.

## The discipline

The laws the stacks obey, quoted from the code that enforces them:

- **The windows** — coyote 120 ms, buffer 140 ms (R-GF-03): both named, both under the 150 ms line. A flip pressed 120 ms after leaving a surface still launches; pressed 140 ms before one arrives it is held until it does.
- **The hit-stop law** — the freeze holds 60 ms inside the 40–80 ms band, never stacked, at most one per 1000 ms, and reduced motion trades it for a clean cut (R-GF-01/06). Only a full-power release earns it, never inside an input-critical window, never on top of a slow-mo beat.
- **The spacing ledger** — no two signature beats inside 20 s (R-SM-06). The scripted beats are recorded, the big-fall slow motion is the beat that yields, and the clear card is the breathing space the rule banks on.
- **Tier parity** — every timing above is the same on every quality tier; only the ceilings move: 260/500/900 concurrent particles and the animation layer under `1.5 ms` p99 on the mid-tier reference. The freeze, the lunge and the windows never drop with the tier (R-GF-13).
- **The reduced-motion path** — the freeze, the shake and the dolly all step aside; the cut, the flash and the cards carry the meaning on their own (R-GF-11's law: visual juice carries meaning).
- **The shake grammar** — one shake source a moment, scaled by impact, never stacked: two shakes back to back read as a fault, not feedback.
