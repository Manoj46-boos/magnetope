# The event vocabulary

Generated by `npm run docs` from the telemetry module’s own grammar. The suite re-renders this file and compares it byte for byte, checks that every record the code makes is in this table, and replays a real attempt to hold the payloads to the grammar (R-AN-01).

Anonymous gameplay telemetry in Poki’s `measure(category, what, action)` shape — nothing identifying, nothing outside the first-party SDK. The channel carries its own law, read off the platform’s live validator: the three arguments may use letters, digits, `_ : . + |` and the space, and together may hold at most two runs of digits. So the grammar speaks in enumerated words and single bare numbers — no key=value pairs, and no coordinates: the fall’s position is a data class the channel cannot carry, so the recorder keeps the height and the grade and the weekly difficulty review reads per-level numbers.

| retry | the level id | the bare gap in ms since the last fall | an attempt begins after a fall |

| time | the level id | the bare clear time in seconds | a clear is recorded |
| fallcount | the level id | the bare number of falls in the attempt | an attempt ends with any |

## The laws

- **Batched, never streamed** — records queue in memory and flush only at natural stops: never mid-run, never during an ad.
- **The queue is capped** at 200 records; the oldest drop first, never the newest.
- **The channel’s own alphabet is the whole law** — every record ships inside A-Z, a-z, 0-9, space, `-`, `_`, `:`, `.`, `+` and `|`, with at most two runs of digits across category, what and action together (R-AN-03). The suite holds every payload to both halves, because the live SDK drops what breaks either.
- **Every visit opens with its boot record** — first-time or returning, with the locale, device class and tier it booted on — so every number the readers emit splits by segment (R-AN-09).
- **The ad lifecycle rides the SDK’s own channel** — impressions and accepts are the host’s business, not the page’s.
- **Absence changes nothing** — a blocked or missing channel costs the queue its audience, never the game its progress (R-AN-08).

## The readers

The export loop keeps its four — heatmap, cluster, records, difficulty — and gains three: the session-0 funnel, the economy pacing medians and the dangle-choice ratios (R-AN-04). One command reads all six sections back from a week’s export (R-AN-07, R-RT-10): `npm run friday -- export.jsonl`. The KPI each number arms lives in KPI.md. The cluster and heatmap modules stay as the local lab: their input is synthetic points, because the platform’s channel no longer carries positions to read.
