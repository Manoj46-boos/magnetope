## How this ledger is kept

Poki's guidance asks for the how and the where of AI use; this file answers with a row per
session, the tool that produced the work, and — the part that matters — the human decision
that shaped it. The premium era (W1 onward) was directed under standing laws the developer
set before the first workstream was commissioned: match the existing code's pattern and write
in it, no machine-made comment walls, real behavioural tests rather than string matches,
deploy and play the build before every push, professional commits, and one complete part per
session with an honest report of what is left.

Where a verdict still needs the developer's own hands — a playtest, a real device, a human
panel — the row does not hide behind a blank. It names the verdict and the gate it is owed
to. Every "Owed before submission (M5)" line above is a promise the developer has not yet
been able to keep, written as one.

Rules this project follows (from the PRD):

- Generated output is a draft. Every level, asset and tuning number is reviewed and owned by the developer.
- Levels are only shipped after the planner bot verifies them **and** a human has played and balanced them.
- No watermark or prompt text may appear in any shipped asset.
- Art is redrawn or re-modelled by hand before it enters the game; raw generator output never ships.
